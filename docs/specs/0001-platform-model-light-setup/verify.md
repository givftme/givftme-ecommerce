## Release evidence

Record database migration dry run counts, unresolved legacy facts, policy tests, provider test configuration and results, browser/device/network settings, and each unmet integration gate. A test fixture provider does not establish working phone OTP. A stored preference does not establish delivered reminders. A completed slice does not mark the whole feature done while required provider, sharing, or guest handoff gates remain unmet.

Review relevant existing tests before extending them. Prioritize meaningful domain tests for canonical dates, inheritance, ownership, duplicate/idempotent operations, import normalization, and migration replay. Browser tests prove the auth boundary and state transitions; database integration tests prove constraints and deletion behavior. Avoid snapshot tests that merely restate component markup.
